# INT257 Viva Preparation — TasdiqCert

## What is TasdiqCert?
TasdiqCert is a digital certificate issuance and verification platform. An institution administrator can issue a credential with a unique ID. A verifier can enter the ID or scan its QR code to check the current database status.

## What is Next.js?
Next.js is a React framework that adds routing, server rendering, route handlers, layouts and other application features.

## Why use Next.js?
It supports a structured full-stack application with frontend routes and backend endpoints in one project.

## What is App Router?
App Router is Next.js's file-system routing approach based on the `app` directory. A `page.jsx` file creates a route and `layout.jsx` provides shared UI.

## Why JavaScript instead of TypeScript?
This project is configured in JavaScript ES modules and JSX. It does not include TypeScript source files, a TypeScript compiler or `tsconfig.json`.

## Server Components vs Client Components
Server Components render on the server and are useful for database-backed content. Client Components use the `use client` directive when browser interaction or React state is required.

## What is Supabase used for?
Supabase hosts the PostgreSQL database. The Next.js server connects to it through Prisma using the private `DATABASE_URL`. The database password is not exposed to browser code.

## What is Prisma?
Prisma is an ORM that provides a generated JavaScript client for reading and writing database records. The schema describes users, institutions, certificates and verification logs.

## How does authentication work?
The registration and login APIs validate input. Passwords are hashed with bcryptjs. After successful sign-in, the server signs a short-lived JWT and stores it in an HTTP-only, same-site cookie. Admin routes and APIs check the session role.

## How does certificate issuance work?
An authenticated institution administrator submits recipient, email, course and expiry details. The API validates the request, creates a unique certificate ID, stores the record in PostgreSQL and writes an audit entry.

## How does verification work?
The public verification page looks up the unique certificate ID. The application resolves revoked and expired statuses, records a verification log and displays the institution, recipient, course and current status.

## What is a QR code used for?
A QR code encodes the public verification URL. Scanning opens the certificate verification route. The QR itself is not proof of authenticity; the server checks the current database record.

## How does PDF generation work?
The authenticated PDF endpoint reads the certificate, creates a landscape PDF with PDFKit, embeds a QR code generated by the QRCode package and returns it as a download.

## How does bulk upload work?
An administrator uploads a CSV file. The API reads the header columns, validates required recipient fields and creates one certificate per valid row. It returns a count and a list of rows that need correction.

## What is Zod?
Zod validates incoming request data so invalid certificate requests can be rejected before database writes.

## What should be improved before production?
Add email verification and password reset, rate limiting, comprehensive automated tests, stronger institution onboarding, monitoring and backup policies, and a formal security review. Change the seeded demo password before deployment.
